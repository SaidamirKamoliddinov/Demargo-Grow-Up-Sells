## 🇬🇧 English

### Overview
**Demargo | Grow Up Sells** is an international digital freight forwarding and supply chain platform designed for businesses, e-commerce, manufacturers, and trade companies worldwide. It optimizes import and export logistics across Ocean, Air, and Road freight with speed, transparency, and cost efficiency.

### Key Features
- **🌊 Ocean Freight:** International container shipping with optimized routing.
- **✈️ Air Freight:** Fast-track delivery for urgent and high-value cargo.
- **🚛 Road Freight:** Efficient regional and cross-border trucking networks.
- **⚡️ Smart Pricing:** Automated cost evaluation for competitive logistics rates.
- **📱 Responsive Design:** Fully optimized UI/UX for desktop and mobile devices.

## 🇷🇺 Русский

### Обзор Проекта
**Demargo | Grow Up Sells** — международная цифровая логистическая веб-платформа для автоматизации грузоперевозок и цепочек поставок. Проект разработан для B2B-сегмента, E-commerce компаний, производителей и торговых предприятий, позволяя оптимизировать логистику через морские, авиационные и автомобильные перевозки.

### Основные Возможности
- **🌊 Морские Перевозки:** Международные контейнерные перевозки с оптимизацией маршрутов.
- **✈️ Авиаперевозки:** Экспресс-доставка срочных и ценных грузов.
- **🚛 Автомобильные Перевозки:** Эффективная логистическая сеть для региональных и международных маршрутов.
- **⚡️ Расчет Стоимости:** Автоматический подбор оптимальных тарифов и сроков доставки.
- **📱 Адаптивный Интерфейс:** Удобный UI/UX для мобильных устройств и ПК.
